# Contributing

Run `python -m unittest discover -s tests -v` before submitting a change. Use synthetic data for regression checks and keep vendor data and generated market-data outputs out of pull requests.

For numerical discrepancies, include the command, configuration, package versions, input hashes and adjustment policy, relevant dates, expected behavior, and observed behavior. Label paper-reported, reconstructed, and synthetic quantities clearly. Preserve archived file bytes; add new interpretations to documentation rather than rewriting historical evidence.

The scope of this repository is the published six-asset BCT study. Explain any change to information availability, targets, temporal splits, or evaluation policy. A visual or documentation change does not need a new statistical experiment.
