## وضعیت فعلی

کد و تنظیمات تاریخی مقاله بازیابی شده است؛ فایل‌های خروجی تاریخی فقط سرستون دارند و پیش‌بینی‌های اصلی یا نتایج واقعی هر فولد در آن نسخه موجود نیست. اعداد مقاله با برچسب «گزارش‌شده در مقاله» نگهداری می‌شوند. بازسازی عمومیِ برنامه با دادهٔ مصنوعی آزمایش شده است؛ تطابق عددی با اجرای اصلی هنوز تأیید نشده است.

## اجرای ساده

پس از نصب پایتون ۳٫۱۱ یا ۳٫۱۲، مخزن را دریافت کن. دستورها را در پوشهٔ اصلی پروژه اجرا کن:

```bash
python -m venv .venv
```

در ویندوز Command Prompt محیط را فعال کن:

```bat
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python tools/smoke_run.py
```

دستور آخر، هر سه مدل را روی دادهٔ مصنوعی اجرا می‌کند. این خروجی‌ها نتیجهٔ مقاله نیستند. برای دادهٔ بازار، فایل‌های CSV را مطابق [راهنمای داده](data/README.md) آماده کن؛ راهنمای کامل اجرا در [نسخهٔ انگلیسی](README.md#quick-start) آمده است.

## نتیجه‌های گزارش‌شده

مقاله کاهش میانگین خطای مطلق را در مقایسه با GARCH برابر ۵۸٫۰٪ و در مقایسه با Persistence برابر ۳۰٫۶٪ گزارش می‌کند. این مخزن اعداد را از مقاله نقل می‌کند؛ آن‌ها را به‌عنوان خروجی بازتولیدشده معرفی نمی‌کند. کد بررسی حسابی جدول‌ها نیز موجود است:

```bash
python tools/audit_reported_results.py
```
