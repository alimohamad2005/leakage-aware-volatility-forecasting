# Public runner and output contract

## Forecast origin and target

Forecasts are formed after the close of observation `t`. Features use only daily bars at or before `t`. The target is the sample standard deviation (`ddof=1`) of log returns `t+1` through `t+5`, multiplied by `sqrt(A)`; `A=252` for the five exchange-traded instruments and `A=365` for BTC-USD. The last five bars cannot be scored because future returns are unavailable.

`features.py` computes 36 variables adapted from the archived scaffold. Its feature definitions are inspectable; they are not a claim that the precise original feature implementation has been recovered. Dates are never randomly shuffled or filled. Leading warm-up rows are trimmed; invalid interior features fail explicitly.

## Temporal model selection

The outer candidate training window contains 756 observations; its last five label origins are purged. The next 63 observations form the test window, and boundaries advance by 21 observations. At every training/test boundary, the latest retained training target must end by the information cutoff. The target-end date is written to the fold outputs.

The reconstruction reserves the last 63 admissible training origins for inner validation, purges the five preceding origins, selects LightGBM's number of trees with 30-round early stopping, and refits on all admissible outer training origins. The 63-observation inner length is a documented reconstruction default; the recovered scaffold does not specify the original executed inner split. Row subsampling is activated every iteration (`subsample_freq=1`). LightGBM volatility predictions are floored at `1e-8`.

Persistence predicts the trailing five-return sample volatility at the current origin. GARCH fits a zero-mean Student-t GARCH(1,1) to training-period returns observable through the prior cutoff. It updates its variance state through each observed origin return and averages the next five conditional variances before converting to annualized volatility. Failed optimizations stop visibly.

## Overlapping test windows

The 63/21 test scheme deliberately overlaps. `fold_metrics.csv` retains separate fold ICs and MAEs. `predictions.csv` records the fold identifier so repeated dates are identifiable. For date-level loss summaries and SPA, the runner retains the **earliest fitted fold** at each asset/model/date and sorts dates chronologically. This explicit deduplication policy avoids treating multiple forecasts for one realized date as independent observations; it is a reconstruction convention, not a recovered original aggregation policy.

## Inference on a new run

`analyze_outputs.py` uses the `arch.bootstrap.SPA` implementation with studentization, a stationary bootstrap, 10,000 replications by default, mean block length 10, and seed 42. Each benchmark is compared separately with the LightGBM challenger; lower, consistent, and upper p-values are saved. This differs from any unrecovered original joint comparison or block selection.

Newey–West inference fits an intercept to chronologically ordered fold ICs with a HAC lag of 10 (or fewer for very short smoke runs). The annualized fold-IC ratio uses `sqrt(A/21)` and is not a portfolio performance measure. Neither the historical “SPA-like” CSV schema nor published p-values are reused as computed outputs.

## Files generated by the runner

| File | Contents |
| --- | --- |
| `predictions.csv` | Date, target end, asset, fold, model, actual, forecast, absolute error |
| `fold_metrics.csv` | Training/target/test boundaries, information cutoff, sample count, MAE, IC, chosen trees |
| `unique_date_mae.csv` | One origin per asset/model/date; count and MAE |
| `run_metadata.json` | Explicit reconstruction status, config, input hashes/ranges, package/Python versions |
| `spa_tests.csv` | New SPA comparisons, if the analysis command is run |
| `nw_ic_tests.csv` | New fold-IC inference and annualized ratio, if the analysis command is run |

The risk-budget decision layer, trading costs, LSTM, SHAP, and regime analysis are not implemented as executed results in this public runner.
